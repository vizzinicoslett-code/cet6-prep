# 内容来源与使用记录

查阅日期：2026-10-20（Asia/Shanghai）。本文件记录本次实际联网研究与取舍。搜索结果仅用作发现入口；进入正文核对后才采用内容。网站中的 `sources` 为对应题目提供可打开的追溯链接；来源站点可能改版、限流或失效。

## 内容边界

- 作文表达 101 条、翻译表达 151 条；用法说明、分类、作文例句均由本站原创编写。它们是通用语言片段，不是某篇商业范文的摘抄，也不宣称是官方认可表达。
- 作文与翻译各有 33 条**主题目录**，覆盖 2021—2025 年各 6 月、12 月，以及已举行的 2026 年 6 月，共 11 个场次。没有收录尚未举行的 2026 年 12 月题目；2022 年 9 月、2023 年 3 月延考暂未纳入。
- 全部目录记录使用 `partial`，界面应解释为“主题资料，原文 / 套数未完整核验”。这不是 66 套完整原卷。多个来源对相同主题的套号排序不同，故统一显示“待核定”，不把网站编号当作官方编号。
- 仅保存年份、月份、主题名称、简短原创中文摘要、关键词、来源链接。**没有存储中文翻译原题全文、第三方完整范文、参考译文、商业题库页面、PDF 或整套 MP3。** 完整题目需要到原始来源查看。`prompt` 本身也明确说明是摘要。
- 作文写作思路由本站独立编写，是学习建议，不是官方评分细则。翻译的逐句练习与英文参考由本站原创编写，页面逐条写明“原创练习”；它们不是原题节选，也不是原题译文。
- 没有为开放网页推断再分发许可。公开可访问、仅供学习、非商业使用等说明，不等于允许我们在公开 GitHub 仓库重新分发整篇内容。
- 每个来源的存储内容限于短主题事实摘要；不直接引用第三方英文句子。研究过程中没有因工具可读而整页复制到项目。未采用付费内容、网盘文件、带水印资料或不明来源音频。

## 已发现的冲突与不采用资料

1. [新东方 2026-06 另一翻译汇总](https://cet4-6.xdf.cn/202606/15233006.html) 把本场次列为三篇文化类翻译，而同站另一正文与南大页面显示技术应用主题；正文结尾还混写四级。该页已实际查阅，**不作为预置真题依据**。以两处可对照的主题建立目录，仍标不完整。
2. 2024-12 作文在南大与新东方的顺序不同；2025-12、2026-06 同样出现套号差异。本站不自行拼成“官方第 1 / 2 / 3 套”。目录 ID 采用日期和主题，不以争议套号绑定题目。
3. [深圳技术大学图书馆讲义](https://lib.sztu.edu.cn/file/uploads/sztu/20250609/287b5397248d4d2d8bfc4877238d4d4b.pdf) 可搜索到，但两次正文抓取失败；未把搜索摘要当作独立核验材料。
4. 无忧考网、部分学习啦页面、B 站视频及个别新东方移动页面本次出现 403、412、超时等失败。失败页面不作为唯一内容证据，已用可读正文替换。记录这些失败不表示用户以后必然无法打开。
5. 较新复盘 / 预测文章曾混入不对应年份的作文、错误题型或宣称唯一官方答案。本站以当年可读资料及跨站主题对照为优先；没有复制这些页面的长文或答案。

## 本版缺口与后续补充条件

全部 66 个条目目前是部分核验的主题目录，不能宣称完成 2021—2026 完整真题库。尤其单一来源条目、索引确认条目、套数映射和原文授权均待补。新增完整原文前，应取得可公开再分发的明确使用条件；新增标准答案前，应独立核对题目、选项内容与答案，而不只比较字母。不得将原创同主题练习改标为真题。
