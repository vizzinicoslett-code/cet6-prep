- 本站收录 1 组阅读真题考点（2 题）、1 组听力真题考点（1 题）。它们是少量节选，**不构成完整真题试卷**。

## 原创音频

`public/audio/original-campus.wav`：本项目自编校园自行车维修活动通知，由 Windows 系统 `System.Speech` 的 Microsoft Zira Desktop 离线合成，语速参数 `Rate = -1`，16 kHz、16-bit、单声道 PCM WAV。实际核对文件头：时长 **42.98 秒**，文件大小 **1,375,246 字节**。不是考试录音，没有使用下载的第三方音频。文稿收录在 `src/data/practice.ts`，提交答题后才显示。

播放器使用原生 `HTMLAudioElement` 控件，支持播放 / 暂停、拖动、当前 / 总时长，以及 0.8× / 1× / 1.2× / 1.5×。实际可解码的文件格式由浏览器决定；损坏或不支持的音频显示错误与重试操作。

## 用户本地材料

JSON 格式示例可从阅读 / 听力页面下载。导入先校验并显示预览，确认后写入 IndexedDB 的 `settings` 条目 `practice-imports`，纳入普通 JSON 数据备份。每篇有独立 ID；同 ID 经用户确认后更新，其他本地题包保留。上限 50 篇，每篇 100 题，单文件 5 MB。用户材料始终标注“本地题包 · 未核验”，不根据用户填写的年份自动认证为真题。

导入器只接收普通数据，React 以文本显示；来源仅允许 HTTP(S) URL，远程音频地址不导入。题目、答案、选项键、解析、年份月份、ID 都需完整有效，失败不会修改既有题包。听力 JSON 需包含 `transcript`，阅读 JSON 需包含 `passage`。

用户导入音频以 Blob 保存在 IndexedDB 的 `audioFiles` 表；当前选择以 ID 保存在 `settings`。刷新页面可以恢复。100 MB 文件上限是应用限制，不保证每个浏览器都有相应空间；清理站点数据、隐私模式或浏览器存储回收都可能使音频丢失。**JSON 备份不包含音频 Blob，用户需自行保留原始文件。**

答题前不会渲染答案、解析或听力稿；提交时要求每题已选，并保存一条 `practiceRecords` 记录。重练产生新的完成记录，列表显示最近一次成绩；未提交的答案不会假装已完成。
