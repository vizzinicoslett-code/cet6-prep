# 架构与数据

## 模块

- `src/App.tsx`：Hash 路由、导航、首页、本地数据统计与状态。
- `src/features/Words.tsx`：单词管理、批量预览与复习任务。
- `src/features/Expressions.tsx`：作文/翻译表达、个人积累、收藏与真题主题目录。
- `src/features/Practice.tsx`：阅读/听力、题包导入、播放器与成绩。
- `src/features/Settings.tsx`：外观、导出、验证恢复、清空、持久存储申请。
- `src/data/`：静态预置资料，与个人数据分开。
- `src/lib/`：独立纯函数，日期、复习算法、解析搜索、答题评分。
- `src/storage/`：IndexedDB 事务与备份校验，不把全部数据塞进一个 JSON 字符串。

## IndexedDB schema v1

数据库名 `cet6-prep`，版本号 `1`，主键均为 `id`。

| 表                     | 用途                                                 | 索引                            |
| ---------------------- | ---------------------------------------------------- | ------------------------------- |
| words                  | 单词、释义、备注、复习计数/状态、日期                | english（唯一）、nextReviewDate |
| wordReviews            | 每次评分与时间                                       | wordId                          |
| writingExpressions     | 作文个人表达                                         | —                               |
| translationExpressions | 翻译个人表达                                         | —                               |
| favorites              | 预置表达收藏                                         | —                               |
| practiceRecords        | 答题、成绩、完成时间                                 | —                               |
| settings               | 外观、复习偏好、本地题包（结构化数组）、选中音频标识 | —                               |
| audioFiles             | 用户导入音频的 Blob、文件名、时间                    | —                               |

`onupgradeneeded` 管理建表/索引，未来迁移需增加数据库版本。`onversionchange` 关闭旧连接；升级被其他标签页阻挡时给出错误。保存复习与历史、删除单词与历史、恢复备份及清空均使用对应的原子事务。多个标签页同时写入也会再次检查重复词与当前单词状态。

只有主题偏好镜像到 `localStorage`，供首次绘制前设置主题；真实设置也在 IndexedDB 和备份中。任何学习内容都不上传。

## 单词复习

使用本地日历日期 `YYYY-MM-DD`，避免 UTC 在深夜改变“今天”。新增单词当天到期；筛选 `!mastered && nextReviewDate <= today`。优先级依次是不认识次数、模糊次数、逾期日期、新词与创建时间。

- 认识：连续次数加一，对应间隔 1、2、4、7、14、30 天；连续六次认识后标记掌握。
- 模糊：连续次数减一（最低 0），间隔缩为当前间隔一半，限制在 1–2 天。
- 不认识：连续次数清零，间隔 0，当天可再次进入下一轮。
- 手动掌握：从到期队列排除；恢复复习则重置连续状态，当天到期。

每轮开始时固定队列与提问方向，因此答错不会在同一轮无限循环。完成后提示用户稍后再复习不认识的词。自动模式包含全部到期词；数量上限截取排好优先级的队列。评分写入成功后才进入下一题，失败时保留当前题供重试。

此算法是透明的个人学习排程，不声称是经个体校准的记忆模型。

## 备份与故障保护

JSON 备份外层包含 `app`、`version`、`exportedAt`、`audioExcluded` 与七表 `data`。验证日期、必填字段、计数一致性、重复主键/单词、记录关联、枚举类型及 JSON 安全性。先完整验证，再在一个事务中替换七表；故障注入测试核对回滚后旧数据仍在。

音频为独立 Blob，不转换为巨大 Base64 JSON。已导入音频刷新后可继续使用，但仍受浏览器配额、存储清理、设备策略限制。备份恢复保留当前音频；清空操作通过弹窗加输入“清空”两次确认。

## PWA 与 Pages

静态资源路径从 Vite `base` 生成。Hash 路由的所有页面向服务器请求同一个站点入口。manifest 的 scope/start_url/icon 路径相对，Service Worker 注册路径与发布子路径一致。

`scripts/build-pwa.mjs` 枚举构建资源，根据文件内容生成缓存版本；离线预缓存 HTML、JS、CSS、图标、manifest 与原创音频，不缓存第三方来源站。更新出现时让用户先完成当前练习，再主动更新刷新；没有通知权限请求或 Web Push。

## 验证范围

Vitest 重点验证纯函数和事务语义；Playwright 使用无头 Chromium 与每用例独立浏览器上下文，验证可见交互、持久化、备份、评分前答案隐藏、320/390/768/1280 的浅深两色布局、离线。生产 Pages 站点另运行同一套浏览器验收。桌面/手机截图人工检查不代表已在真实 iOS/Android 硬件安装测试。
