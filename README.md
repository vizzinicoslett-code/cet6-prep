# 六级备考

一个安静、专注、无需登录的个人 CET-6 学习空间。所有学习数据留在当前浏览器的 IndexedDB 中。

- [在线使用](https://vizzinicoslett-code.github.io/cet6-prep/)
- [资料来源与内容边界](docs/sources.md)
- [阅读、听力样本来源](docs/practice-sources.md)
- [架构与数据说明](docs/architecture.md)
- [验收记录](docs/acceptance.md)

## 本地运行

需要 Node.js 22.12+（推荐 Node.js 22 或 24）、npm。

```sh
npm install
npm run dev
```

```sh
npm test                       # Vitest
npm run build                  # TypeScript + Vite + 离线资源构建
npx playwright install chromium
npm run test:e2e                # 无头浏览器，自动启动生产预览
```

开发预览默认位于 `http://127.0.0.1:5173`。生产预览可运行 `npm run preview`，默认端口 4173。开发模式不注册 Service Worker。

## 日常使用

1. 在「单词」中记下容易忘记的词，支持逐条添加和批量粘贴。重复单词可以选择更新释义。
2. 使用随机混合、英译中或中译英复习；先回想，点击显示答案后再评分。
3. 在作文和翻译表达库中收藏表达，或新增、编辑自己的积累。
4. 阅读、听力提供来源可追溯的真题考点节选和明确标注的原创练习。完整题包可按下载的 JSON 模板自行导入；本地音频可单独导入。
5. 每周到「设置与数据管理」导出 JSON 备份。备份不包含音频，请保留原始文件。

手机可通过 Safari 分享菜单或 Android 浏览器菜单「添加到主屏幕」。首次联网载入正式站点后，核心页面、单词复习、个人表达以及原创音频支持离线使用。不提供通知、后台提醒或云同步。

## 内容范围

预置表达均为自主整理。作文、翻译真题提供 2021–2026 年已考场次的主题索引、来源链接和原创学习思路；不是整套原卷的转载。不同资料站套号冲突时标为待核定，未验证内容明确标记待补充。翻译逐句练习为同主题原创练习，不能视为中文原题。2026 年 12 月考试尚未举行，不收录。

阅读和听力的真实样本是少量考点节选；其中中文题意/选项为转述。完整文章、听力原文及不明授权的整套 MP3 不进入仓库。内置音频为原创文稿的合成朗读，明确标注非真题。请从页面链接访问原始资料，或导入自己有权使用的题包与音频。

## 数据与备份

每台设备、每种浏览器、每个网站来源分别保存数据。开发站、生产站、其他浏览器之间不会自动同步。隐私模式、清除站点数据、系统空间不足时的存储清理都可能使记录丢失；「申请持久存储」的结果由浏览器决定，不能替代备份。

备份包含七个结构化表：单词、复习历史、作文个人积累、翻译个人积累、收藏、练习记录和设置（含个人题包）。导入先验证所有记录，确认后在一个 IndexedDB 事务中恢复；任何写入失败会回滚。本地音频 Blob 不纳入 JSON 备份，恢复时保留；清空学习数据会删除本地音频。

## 部署

推送 `main` 后，GitHub Actions 依次安装依赖、运行单元测试、构建、运行 Playwright，再部署 GitHub Pages。仓库 Pages 的 Source 应为 GitHub Actions。`VITE_BASE_PATH` 从仓库名生成，应用使用 Hash 路由，二级页面刷新不依赖服务端重写。

构建也支持默认相对路径 `./`。迁移到其他仓库后，更新 README 的站点地址即可；工作流自动使用新仓库名。测试已有站点可设置 `BASE_URL` 为完整站点地址（含子路径）后运行 `npm run test:e2e`。

技术栈：React、TypeScript、Vite、原生 CSS、原生 IndexedDB、PWA、Vitest、Playwright、Lucide 图标。无后端、账号、付费 API 或数据服务器。
